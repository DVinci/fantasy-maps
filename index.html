Generating fantasy maps

An interactive tutorial based on Martin O'Leary's terrain generation algorithm, the engine behind @unchartedatlas.

This page is a fully interactive recreation of the fantasy map generator described in the original mewo2/terrain project. Each section below lets you explore a different stage of the algorithm, from random point generation through to a complete labelled map.

Placing random points

The first step is to generate a set of random points and then improve their distribution using Lloyd relaxation (moving each point to the centroid of its Voronoi cell). This gives us a nicely spaced irregular grid to work with.

Building the mesh

From the points, we construct a Voronoi diagram and its dual Delaunay triangulation. The vertices of the Voronoi diagram form our mesh, which is the graph we'll do all our computations on.

Sculpting the height map

We build up a height field by adding together simple primitives: slopes, cones, and blob-shaped mountains. Click the buttons below to add features one at a time and watch the height map evolve.

Erosion

Real terrain is shaped by water erosion. We simulate this by calculating water flow across the terrain and eroding proportionally to the flow rate and slope. This creates river valleys and smoother terrain. Sinks are filled first to ensure water can always flow downhill to the edge.

Rendering features

With the height map complete, we can render the coastline, rivers (where water flux exceeds a threshold), and slope shading (short strokes indicating steepness). Toggle each feature on and off.

Placing cities

Cities are placed by scoring each location based on water flux (good for trade), distance from other cities (spreading out), and proximity to the centre of the map. The highest-scoring location gets the next city.

Territories & borders

Territories are computed using a priority-queue based expansion from each major city, weighted by terrain difficulty. Borders are drawn where adjacent cells belong to different territories.

Complete map

Put it all together: generate a full map with terrain, erosion, coastlines, rivers, slope shading, cities, borders, territory labels, and procedurally generated fantasy names. Each click produces a completely new random map.
